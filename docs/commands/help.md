# .help

Show general usage or help for a specific command.

## Syntax

```text
.help [command]
```

Without an argument, the bot explains the gold/blue coins, lists commands, and links to the Copy Bot application and command documentation. With an argument, it sends help about that command privately.

## Examples

```text
.help
.help paste
.help .snake
```

The command argument may include its leading period. Use a lowercase command argument, such as `paste`. An unknown command argument produces an error.

No selection or edit permission is required. The short in-game list includes all 15 public commands, including [`.skipair`](./skipair.md). Use `.help skipair` for its details.
