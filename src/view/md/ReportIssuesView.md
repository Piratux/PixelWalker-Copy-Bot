# Report issues

Found a problem with PixelWalker Copy Bot? Please [report it here on GitHub](https://github.com/Piratux/PixelWalker-Copy-Bot/issues).

Check existing issues before opening a new one. Include the steps to reproduce the problem, what you expected to happen, and what actually happened. Screenshots and error messages can help.

Never include your password, access tokens, or other private information in a report.
